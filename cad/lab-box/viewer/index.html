What it is
A box that holds the FPGA board under a heater clamp, with sensors and a controller around it, so an AI agent can change the chip's real physical conditions and measure what happens.
Why it exists
Agent-designed chips fail on physics nobody checked. This box gives agents measured ground truth from real silicon: temperature, power, clock and pin behaviour.
How an agent uses it
set_temperature → wait for "stable" → sweep the clock → read pass/fail and power → build a shmoo map of frequency against temperature.
